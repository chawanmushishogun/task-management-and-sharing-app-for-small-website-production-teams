## このアプリを一言でいうと

**Web制作の案件を、プロジェクトごとに並べて管理するアプリ。**

Asana を参考にしているが、**ログインの概念がない**。
「誰の画面か」を持たず、少人数で1つの盤面を共有して使う前提にしている。

難しいのは「タスクを並べる」ことではなく、
**同じタスクを3つの画面（リスト・ボード・全タスク）から編集できるようにすること**。
どこで直しても同じデータが変わる必要がある。
詳しくは [02-全体像.md](02-全体像.md) を参照。

## 動かし方

```bash
# 準備（最初の1回だけ）
npm install

# 開発用に起動する（ファイルを保存すると画面が自動で更新される）
npm run dev

# 型のまちがいだけを調べる
npm run typecheck

# 本番用に組み立てる（型を見てから、配布用のファイルを作る）
npm run build
```

起動したら http://localhost:5173 を開く。

サーバーを使っていないので、**データはブラウザの中に保存される**。
別のブラウザで開くと、別のデータになる（→ [01-用語集](01-用語集.md#localstorage)）。

データを最初の状態に戻したいときは、
DevTools（F12）の Application → Local Storage から
`asana-clone:` で始まる項目を消す。
